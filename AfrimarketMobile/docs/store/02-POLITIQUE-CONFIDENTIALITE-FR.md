## 2. Quelles données nous collectons

| Donnée | Exemple | Finalité |
|---|---|---|
| Compte | Nom, numéro de téléphone, mot de passe (haché, jamais en clair), rôle (acheteur/vendeur/livreur/admin) | Création et connexion au compte, sécurité |
| Profil boutique | Nom de boutique, description, produits, prix | Publication et gestion des boutiques |
| Avis / notes | Évaluation laissée sur une boutique | Amélioration de la marketplace |
| Localisation | Position approximative/précise (livreurs) | Suivi et création de livraisons |
| Photos | Photo de boutique, produit, avatar | Vous les publiez vous-même |
| Notifications | Token push Expo | Vous prévenir des commandes/livraisons |
| Transactions | Montant, téléphone de paiement, statut | Régler via notre passerelle (CinetPay) |
| Support | Message d'aide si vous nous écrivez | Répondre à votre demande |

**Nous ne collectons PAS** : adresse e-mail, contacts, messages privés,
biométrie, données de santé ni données d'enfants.

## 3. Finalité / base légale

Les données sont traitées pour : l'exécution du contrat (fournir le service),
la sécurité des comptes, et (si applicable) votre consentement (GPS, caméra,
notifications — révocables à tout moment dans les réglages de l'appareil).

## 4. Partage

- **Aucune vente** de données à des annonceurs.
- Partage uniquement avec des sous-traitants indispensables : hébergeur
  (Supabase / EAS), passerelle de paiement (CinetPay), push (Expo).
- Contenu que vous publiez (boutique, produits) visible des autres
  utilisateurs, c'est votre choix.

## 5. Durée de conservation

- Comptes et commandes : tant que le compte est actif + durée légale
  comptable/fiscale applicable.
- Données de localisation : transitoires (le temps d'une livraison).
- Après suppression du compte : suppression ou anonymisation conforme.
